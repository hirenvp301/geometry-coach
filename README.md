# Geometry Coach

Interactive Geometry 8 practice app (Edison Township curriculum, Units 0–13) plus MCVSD entrance-exam prep (timed Math and Language Arts practice tests).
A single static page, `index.html`, with no build step.

Deploy: `npx vercel --prod` from this folder, or import this repo in Vercel
(Framework preset: Other, no build command, output directory: `.`).
